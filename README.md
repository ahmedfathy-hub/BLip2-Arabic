# BLIP2-Arabic

This project builds upon [LAVIS](https://github.com/salesforce/LAVIS) library's BLIP2 mdoel and similar as Blip2-Japanese [Repo](https://github.com/ZhaoPeiduo/BLIP2-Japanese)

The main idea is to adapt BLIP-2 using (ViT) as an efficient vision-language with CamelBERT (167GB, 17.3B word) (bert-base-arabic-camelbert-mix) as an Arabic LLM by modifying BLIP-2’s code to integrate CamelBERT and ensuring tokenizer compatibility.

The model has been trained using [flickr30k dataset](https://www.kaggle.com/datasets/adityajn105/flickr30k?select=Images), annotations were translated from English to Arabic using Google Translation API. IT can be obtained from [Arabic annotations](https://github.com/ahmedfathy-hub/Flickr30K_Arabic_Annotations.git)

## Model training

The model  was tained using Google Colab Pro using a high-performance GPU instance with either an NVIDIA Tesla T4 or V100 accelerator (22GB VRAM)

The setup included 53 GB of RAM and 253 GB of disk storage, which was sufficient to handle the substantial memory requirements of pretrained model weights (such as BLIP-2’s 1.5B parameters) 

PyTorch 2.0+ used along with the Hugging Face Transformers library, taking advantage of BLIP-2’s cutting-edge image-to-text generation capabilities. 

To optimize memory efficiency, mixed-precision training (FP16/FP32) applied via PyTorch’s Autocast, which reduced GPU memory consumption by approximately 30% while preserving model accuracy
